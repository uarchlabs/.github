## uarchlabs

uarchlabs is an open source high-performance hardware design organization.
The AI-assisted design process is published alongside the RTL.

### Pacino

Pacino is an 8-issue out-of-order RISC-V RVA23S64 processor in SystemVerilog.
The frontend RTL is complete. One architect directs LLM agents through the
design, and every IA task is published in the
[IA task browser](https://uarchlabs.github.io/pacino/sessions/).

### Projects

- [pacino](https://github.com/uarchlabs/pacino): out-of-order RVA23S64 RISC-V
  processor, with the full co-design record committed alongside the RTL.
- [ticfinder](https://github.com/uarchlabs/ticfinder): finds recurring LLM
  prose constructions in markdown or plain text, so a human can decide what
  to cut.
- [cachegen](https://github.com/uarchlabs/cachegen): cache RTL and C++ model
  generator.
